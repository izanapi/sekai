# 世界ガチャ / BUILD 0.5

世界の物品・現象・法則を収集する、単一HTMLのモバイル向けブラウザゲーム。
`index.html` だけで動作します。ビルド、外部ライブラリ、アカウントは不要です。

## 遊び方

- 生活区画の6台から開始。全24台、1000種類を収録。既存118品に882品を追加しています。
- 図鑑と保管庫は40件ずつ表示し、検索できます。図鑑はガチャ台での絞り込みにも対応。
- 保管すると観測収入、売却すると資金、初回使用と返却で研究点を取得します。
- 初回登録手当、30秒ごとの周辺調査、段階式の調査依頼で運用資金を確保できます。
- 7回連続で既登録品を引くと、次回はその台の未登録品を保証します。
- 16件の組合せ調査は、指定品を同時に保管すると報告できます。品は消費しません。
- 研究点で6種類の常時技能を認可できます。
- 整合率は使用で下がり、報告文が変化します。返却・再計算で回復できます。進行不能にはなりません。

## 起動・保存

`index.html` をブラウザで開くか、このディレクトリで `python3 -m http.server 8765` を実行し、`http://localhost:8765` を開きます。公開時も `index.html` だけを静的配信できます。

同じブラウザ・同じオリジンのlocalStorageに保存します。URLやポートを変えると保存先も変わります。ファイルを直接開く場合の保存対応はブラウザによって異なります。保存できない場合は画面に通知します。

記録タブでJSON形式の書き出し・読み込みができます。未処理の排出物も保存します。不在中の収入は最大8時間分。直近の予備保存からの復旧に対応します。旧BUILD 0.3には保存機能がないため、旧セッションからの自動移行はありません。

## 検証

Node.js 22以降で `node tests/verify.cjs index.html`。

24項目を確認します。全台の排出先と確率、既存35品のデータ保持、排出物の上書き防止、保証抽選、初回使用、報告の二重受領防止、技能、調査間隔、8時間上限、保存復元、予備保存、入力検証、画面描画関数、継続プレイを含みます。

画面描画関数の検証は最小限のDOM代替を用いるロジック検証です。実ブラウザのタッチ操作・レイアウト検証を代替するものではありません。継続プレイは30秒間隔の調査と保管を行う固定乱数のシミュレーションで、プレイ時間や収益を保証しません。

## BUILD 0.4からの継続

保存形式とキーは変更していません。既存118品の名前・レア度・説明・使用文・効果は保持しています。図鑑、保管数、技能、未処理品、受領済み報酬も引き継ぎます。以前に台の全品登録報酬を受け取っている場合、品数が増えても二重には支給しません。全品使用の最終依頼は1000種類で完了します。

追加882品は具体的な対象と短い名詞を中心に、品ごとの説明を用意しています。説明の末尾と試験結果には調査局の共通書式も使用します。日用品は主にN/R、場所・記録・現象から法則・抽象概念へと存在階層が上がります。

1000品すべての通常抽選による到達性、名称の重複、旧118品全データ、40件ページング・検索、旧セーブと最終依頼も自動検証しています。実機でのレイアウト・長期バランス検証は未実施です。

## 実装

データ・スタイル・ロジックはすべて `index.html` 内にあります。各台は固有の排出リストを持ち、通常抽選は存在するレア度の重みを正規化してから同レア内で均等抽選します。保証抽選と優先照会は未登録品から均等に選びます。

保存形式は `version: 1`、保存キーは `sekai-catalogue-v1`。品名と台のIDは保存上の識別子でもあるため、変更時には移行処理が必要です。
